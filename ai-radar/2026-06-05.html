매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • Claude Opus 4.8 출시 (2026.05.28) — 자율적 다단계 추론 + 대규모 코드 리팩토링 강화, 현재 최상위 성능 모델 (출처: hidekazu-konishi.com)
  • Google Gemma 4 12B 공개 (2026.06.03) — 로컬 노트북에서 오디오/비전 실시간 처리하는 온디바이스 멀티모달 (출처: googleblog.com)
  • OpenAI GPT-5.6 출시 임박 (2026.06 예정) — 초저지연 실시간 에이전트 작업 최적화, 6월 중순 발표 예상 (출처: 36kr.com)

🛠️ 개발 툴·스킬

  • MCP(Model Context Protocol) 표준화 — 에이전트-도구 연결 표준으로 자리잡음, 월 SDK 다운로드 9,700만 건 돌파 (출처: dev.to)
  • Microsoft eXecution Containers (MXC) — 로컬 AI 에이전트의 파일접근/코드실행을 안전 격리하는 에이전트 전용 샌드박스 (출처: nvidia.com)
  • Salt Code / Agent Passport — 에이전트 생성 코드의 취약점 실시간 감시 + 에이전트 신뢰성 인증 보안 인프라 (출처: dev.to)

📄 논문·트렌드

  • NitroGen (CVPR 2026) — 게임·물리 환경에서 인간 수준 범용성 보이는 비전-액션 파운데이션 모델 (출처: thecvf.com)
  • DeepSeek-V3 MoE — 6,710억 파라미터를 1/10 비용으로 운용, 프론티어급 성능 구현 (출처: machinebrief.com)
  • The AI Scientist (Sakana AI) — 가설→실험설계→논문작성→동료검토까지 완전 자율 과학 연구 프레임워크 (출처: medium.com)

💡 또리팀 적용 포인트

  • MCP 기반 도구 통합 — 외부 API·로컬 파일 연결을 MCP 규격으로 설계 → 다양한 에이전트 모델과 호환성 확보. 또리삼형제 도구 연동에 직접 적용 가능
  • 멀티 에이전트 오케스트레이션 — 문제 분해하는 ‘리드 에이전트’ + 병렬 처리 ‘서브 에이전트’ 구조. 우리 클또리(지휘)→젬또리/챗또리(서브) 구조와 정확히 일치, 패턴 참고
  • 실시간 코드 보안 레이어 — MXC식 격리 실행 + Salt Code식 취약점 검사를 파이프라인에 통합 (챗또리 리뷰 단계 보강 아이디어)
