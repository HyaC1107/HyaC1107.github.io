🤖 모델/LLM 소식

  • Mistral Large 4 — 총 1.05T 파라미터(활성 파라미터 약 52B) 규모의 MoE(Mixture-of-Experts) 아키텍처 기반 오픈웨이트 멀티모달 모델 공개, 복합 다단계 추론 및 엔터프라이즈 비전 업무 지원 (https://aitoolsrecap.com/mistral-large-4-release)
  • NVIDIA Nemotron 3.5 Suite (Bolt 74B & Super VL) — 문서 분석·고정밀 시각 이해(OCR/표 추출) 및 단일 GPU/에이전트 인프라 환경에 최적화된 오픈웨이트 멀티모달 모델군 배포 (https://aireleasetracker.com/nvidia-nemotron-3-5-suite)
  • Moonshot Kimi K2.5 / K2.6 — 100만 토큰 이상 장문 컨텍스트 지원, 프론트엔드/복합 코딩 및 에이전트 스웜(Agent Swarm) 기반 병렬 자율 실행에 특화된 오픈웨이트 멀티모달 MoE 모델군 (https://reddit.com/r/LocalLLaMA/comments/kimi_k2_5_long_context_models)

🛠️ 개발 툴·스킬

  • Microsoft Project Perception & Agent Guardrails — 레드·블루·그린 전담 에이전트 간 협업을 통해 장기 실행 자율 에이전트의 내부자 위협 및 권한 오남용을 실시간 시뮬레이션·탐지·격리·자동 교정하는 보안 체계 (https://geekwire.com/2026/microsoft-agent-security-guardrails)
  • Mastercard Agent Pay for Machines — x402 등 개방형 프로토콜 기반으로 자격 증명 등록부와 사전 설정된 예산 한도 내에서 AI 에이전트의 데이터·API·컴퓨팅 자원 자율 결제를 지원하는 인프라 툴킷 (https://mastercard.com/news/press/2026/agent-pay-for-machines)
  • Azure MCP Server 3.0 for Visual Studio — Azure Backup, 복원력 관리, Terraform 및 SRE 자동화 도구셋을 통합하여 개발 환경 및 GitHub Copilot 에이전트와 연동하는 공식 오픈소스 MCP 서버 (https://visualstudiomagazine.com/articles/2026/azure-mcp-server-vs-integration)
  • llm-d 1.0 (CNCF/IBM/Google Cloud/Red Hat) — 프리픽스 캐시 인식 지능형 라우팅 및 Prefill/Decode 분리(Disaggregated Serving)를 통해 컨텍스트 집약적 다중 에이전트 서빙 비용을 절감하는 Kubernetes 최적화 분산 인퍼런스 스택 (https://ibm.com/blog/llm-d-distributed-inference-release)

📄 논문·트렌드

  • IF-MAP: Influence-Function-Inspired Agent Prioritization in Multi-Agent Systems — 그래디언트 접근 없이 블랙박스 섭동과 영향도 함수를 통해 다중 에이전트 시스템에서 프롬프트 최적화나 모델 업그레이드 시 전체 시스템 성능 개선 잠재력이 가장 높은 에이전트를 선별하는 프레임워크 (https://arxiv.org/abs/2610.24383)
  • Multi^2: Hierarchical Multi-Agent Decision-Making with LLM-Based Agents in Interactive Environments — 장기 실행 중 발생하는 목표 표류(Objective Drift)를 방지하기 위해 고수준 하위목표 생성(Sub-goal Planning)과 저수준 실행(Action Execution) 에이전트를 계층적으로 분리 설계 (https://arxiv.org/abs/2606.03698)
  • MASS: Recursive Self-Improvement through Multi-Agent Self-Supervision — 외부 인간 피드백의 감독 병목을 극복하기 위해 다중 에이전트의 진화적 워크플로우 최적화 및 자체 궤적 SFT 루프를 통해 비검증 작업에서도 지속적 재귀 자율 개선을 달성하는 연구 (https://arxiv.org/abs/2610.12176)

💡 또리팀 적용 포인트

  • Multi^2 기반 목표 표류 방지 아키텍처 (계층형 분리): CLI 오케스트레이터에서 복잡한 다단계 작업을 진행할 때 상위 플래너(Sub-goal Planner)와 도구 실행 전담 워커(Executor)의 역할을 물리적으로 분리하여, 장기 세션에서 에이전트의 원래 작업 목표 왜곡 현상을 방지할 수 있습니다.
  • IF-MAP 영향도 분석 기법: 여러 에이전트(코드 작성, 정적 분석, 피드백 등)가 연쇄 호출되는 파이프라인에서 작업 실패나 비용 증가의 주요 병목이 되는 에이전트를 역추적하여 오케스트레이터의 프롬프트 튜닝 및 모델 교체 우선순위를 과학적으로 결정할 수 있습니다.
  • Microsoft Guardrails 패턴의 비정상 실행 감지 레이어: 서브에이전트에게 쉘/파일 시스템 제어권을 부여할 때 권한 남용이나 예기치 않은 반복 루프(Reward Hacking)를 실시간 감지하여 즉각적인 격리 및 세션 중단을 처리하는 안전 샌드박스를 구축할 수 있습니다.
