매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 자동 생성 (Windows 작업 스케줄러 ttori-ai-radar, 매일 08:00 · 젬또리 agy Gemini 3.5 Flash (Medium)). 클또리 검수를 거치지 않은 원문이다. [미검증] 태그가 붙었거나 출처가 도메인 홈페이지뿐인 항목은 채택 전 반드시 원문 확인할 것. flash가 학습데이터를 최신 정보로 착각해 내놓는 경우가 있다.

🤖 모델/LLM 소식

  • Gemini 3.7 Flash [미검증] — 코딩 및 에이전트 워크플로우에 최적화된 고효율/저지연 모델로 API 플랫폼 및 개발 도구 연동 강화 (https://google.ai.dev/blog/gemini-3-7-flash)
  • DeepSeek-V4-Pro [미검증] — 1.6조 매개변수의 MoE 아키텍처와 1M 컨텍스트 윈도우를 지원하는 고성능 추론 및 코딩 특화 모델 GA 릴리즈 (https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro)
  • Seedance 2.5 [미검증] — 캐릭터/스타일 일관성을 유지하며 최대 30초 분량의 4K 비디오 생성 및 영역별 편집 기능을 지원하는 전문 비디오 생성 모델 출시 (https://bytedance.com/seedance-2-5)
  • OpenAI GPT-5.6 Sol/Luna 업데이트 [미검증] — 최상위 Sol 등급의 추론 능력 개량 및 무료 사용자 대상 Luna 등급 접근 범위 확장 배포 (https://openai.com/blog/gpt-5-6-updates)

🛠️ 개발 툴·스킬

  • Model Context Protocol ext-apps 확장 규격 — MCP 서버가 샌드박스화된 iframe을 통해 AI 호스트 앱에 대시보드, 폼 등 대화형 UI를 직접 렌더링하도록 정의된 표준 규격 (https://github.com/modelcontextprotocol/ext-apps)
  • Model Context Protocol SDK v2 업데이트 — 2026년 7월 28일 사양을 반영하여 상태 비저장(Stateless) 전송 모델로의 전환을 포함한 대대적인 아키텍처 개선 및 호환성을 제공하는 v2.0 공식 SDK 릴리즈 (https://github.com/modelcontextprotocol/typescript-sdk)
  • 요즘IT 실무용 AI 에이전트 가이드 — 자율 업무 수행이 가능한 최신 웹·코딩 에이전트 및 자율 에이전트의 비교와 실무 활용법 소개 (https://yozm.wishket.com/magazine/detail/2684/)

📄 논문·트렌드

  • Mind Viruses: Self-Propagating Ideas in Multi-Agent LLM Systems — 멀티 에이전트 환경에서 에이전트 간의 상호 설득으로 특정 아이디어나 행동 편향이 전파되는 현상 및 시스템 프롬프트 제어를 통한 방어 방안 연구 (https://arxiv.org/abs/2608.10218)
  • Everyone Conforms, No One Believes: Pluralistic Ignorance in LLM Agent Populations — 집단 토론 시 개별 에이전트가 내부 판단과 달리 집단의 다수의견에 동조하여 정보 왜곡을 심화시키는 복수적 무지 현상 규명 (https://arxiv.org/abs/2608.02758)
  • When Truth Is Distributed: Misinformation Derails Collective Fact Recovery — 분산 에이전트 환경에서 일부의 오정보(Misinformation)가 협력적 사실 발견 프로세스 전체를 방해하고 왜곡하는 메커니즘 분석 (https://arxiv.org/abs/2608.03421)
  • MatrAIx: Population-Scale Simulation Framework — 정적 벤치마크의 한계를 넘어 83억 개의 페르소나 프로필을 기반으로 이종 사용자 상호작용 및 복잡한 에이전트 작업을 시뮬레이션하는 대규모 평가 체계 (https://arxiv.org/abs/2608.06977)

💡 또리팀 적용 포인트

  • MCP ext-apps (SEP-1865) 사양 연동 — 오케스트레이터의 텍스트 터미널 출력 한계를 극복하기 위해, 샌드박싱된 로컬 웹 뷰나 iframe을 띄워 사용자에게 인터랙티브 대시보드나 폼 UI를 직접 제공하여 복잡한 데이터 시각화 및 승인 환경 구축에 활용 가능합니다.
  • MCP SDK v2 업그레이드 및 Stateless 전송 모델 적용 — 상태 비저장 모델을 연동하여 오케스트레이터의 도구 호출 및 상태 관리를 단순화하고 분산 에이전트 실행 시의 세션 유지 관리 리스크를 최소화합니다.
  • Gemini 3.7 Flash 모델 도입 — 오케스트레이터의 고속 도구 호출(Tool calling) 및 서브 에이전트 제어용 기본 라우터로 배치하여 높은 컨텍스트 처리량과 빠른 응답 속도를 저비용으로 확보합니다.
