AI 레이더 2026-06-07

2026년 6월 07일4 min read

  • ai-radar

매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • Claude Opus 4.8 — Intelligence Index 1위, 1,000개 병렬 서브에이전트 오케스트레이션 정식 지원 (출처)
  • GPT-5.6 출시 임박 — 6월 말 예정, 토큰 비용 20~30% 절감 + 에이전트 워크플로우 최적화 집중 (출처)
  • Gemini 3.1 Ultra / 3.5 Flash — Ultra는 200만 토큰 컨텍스트 + 비디오/오디오 네이티브 이해, Flash는 저비용 고효율로 시장 주도 (출처)

🛠️ 개발 툴·스킬

  • MCP 표준화 — Anthropic이 MCP를 ‘Agentic AI Foundation’에 기증, 벤더 중립 표준 확정 + 월간 다운로드 1.1억 건 (출처)
  • MCP Apps 대화형 UI — MCP 서버가 샌드박스 iframe 안에서 대시보드/폼을 직접 렌더링하는 기능 업데이트 (출처)
  • FastMCP / mcp-agent — Python 기반 빠른 MCP 서버 구축(FastMCP) + 다중 MCP 서버 간 라우팅(mcp-agent) 프레임워크 부상 (출처)

📄 논문·트렌드

  • MLEvolve (arXiv:2606.06473) — AI가 스스로 ML 알고리즘을 발견·최적화하는 자가 진화형 프레임워크, 인간 개입 최소화 트렌드 (출처)
  • Latent Space Planning (Cola DLM) — 다음 토큰 예측 대신 잠재 공간에서 전체 논리를 먼저 계획 후 생성하는 아키텍처, 복잡한 추론 성능 향상 (출처)
  • CVPR 2026 — 6/5~7 개최, 화면 인식·조작 멀티모달 LLM(Computer Use) 연구 대폭 증가 (출처)

💡 또리팀 적용 포인트

  • 병렬 서브에이전트 구조 — Claude Opus 4.8의 1,000개 병렬 서브에이전트를 지금 ttori 오케스트레이터에 바로 활용 가능. 클또리가 태스크 분해 → 젬또리/챗또리 병렬 위임하는 패턴 강화할 것 (출처)
  • SKILL.md 표준 — 여러 CLI 에이전트 간 공유 스킬 포맷 부상. 현재 .claude/skills/ 구조와 정렬되니 규격 유지하며 확장 권장 (출처)
  • Stateless MCP 호출 — _meta 필드 포함 비상태형 MCP 사양으로 젬또리·챗또리 호출 시 확장성 확보 가능, 향후 MCP 통합 시 적용 고려 (출처)
