AI 레이더 2026-07-18

2026년 7월 18일5 min read

매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🖐️ 수동 실행 (PM 지시, 클또리 정리). 오늘 08:00 cron이 파일을 안 남겨 세션에서 재실행. ⚠️ 출처가 도메인 홈페이지 수준(tldr.tech, arxiv.org 등)인 항목은 [젬또리] 태그 — 채택 전 원문 확인 권장. arXiv ID 미특정 항목은 사실상 [미검증]에 준해 취급할 것.

🤖 모델/LLM 소식

  • OpenAI GPT-Live 출범 [젬또리] — 실시간 양방향(Full-duplex) 음성 대화 지원, 복잡한 지시·도구 호출은 GPT-5.5로 자동 위임하는 에이전트형 음성 모델 (tldr.tech/ai)
  • ByteDance Seedream 5.0 Pro [젬또리] — 다국어 + 정교한 타겟팅 편집을 갖춘 상용 디자인·프로덕션 특화 멀티모달 모델 출시 (tldr.tech/ai)
  • Gemini 3.5 Flash & Omni 진화 [젬또리] — 경량 구조로 이전 세대 Pro급 성능 상회, CLI·자율 에이전트 오케스트레이션용 모델로 입지 강화 (yozm.wishket.com)

🛠️ 개발 툴·스킬

  • MCP 2026-07-28 사양 확정 — Stateless Core 전환 [공식] — initialize 핸드셰이크·세션 헤더 제거로 표준 HTTP 로드밸런서 호환 확보, MCP Apps(UI 렌더링)·Tasks(장기 실행) 확장 규격 표준화. (지난 며칠 “예정” 소식의 확정판) (modelcontextprotocol.io)
  • Prime Intellect verifiers v1 [젬또리] — 에이전트 RL 평가와 코드/결과물 신뢰성 검증을 자동화하는 오픈소스 Verifier 라이브러리 공개 (tldr.tech/ai)
  • FlowGuard — MCP 보안 검증 프레임워크 [젬또리] — MCP 툴 호출에 시맨틱 분류 + 동적 프로빙을 적용해 악성 툴 인젝션을 실시간 격리·검증 (arXiv ID 미특정) (arxiv.org)

📄 논문·트렌드

  • ICML 2026 Agent Reproductions (7/15~8/2) [젬또리] — AI 코딩 에이전트들이 ICML 2026 논문 핵심 주장을 자동 재현·실행하고 Logbook Judge가 검증하는 대규모 공개 검증 프로젝트 (huggingface.co)
  • AgentCheck & MCPEvol-Bench [젬또리] — 동적으로 진화하는 MCP 서버 환경에서 LLM 에이전트 오작동·에러 원인을 추적·재현·완화하는 벤치마크 워크벤치 (arXiv ID 미특정) (arxiv.org)
  • Sakana AI ‘Smart Cellular Bricks’ [젬또리] — 중앙 서버 없이 분산 로컬 통신 + 신경망만으로 물리 하드웨어가 3D 형상을 자율 분류·재구성 (tldr.tech/ai)

💡 또리팀 적용 포인트

  • MCP Stateless 대응은 이제 “예정”이 아니라 “확정” — 7/28 스펙이 확정됐으니 ttori-tools MCP 서버·biz-ttori 쪽 MCP 통신에 세션 상태 의존이 있는지 점검 목록을 만들어둘 시점. (며칠째 레이더에 반복 등장 = 실제로 오는 변화)
  • verifiers v1식 2중 검증 게이트 — 우리 검증관(audit.py 정적 + LLM 분신) 구조와 같은 사상. 오픈소스 구현이 나왔으니 CG 규칙 확장 시 참고 레퍼런스로 볼 만함.
  • FlowGuard 류 MCP 툴 인젝션 방어 — 우리 철칙 #6(Agent Jacking 방어, 외부 원시 텍스트 필터링)과 정확히 같은 문제의식. 논문 원문 확보되면 team-rules 보강 근거로 사용 가능.

젬또리(Antigravity CLI agy —model “Gemini 3.5 Flash (Medium)” + 실시간 웹 검색) 리서치 · 클또리 정리
