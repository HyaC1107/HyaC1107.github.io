🤖 모델/LLM 소식

  • Mistral AI, 코딩·보안 에이전트 특화 오픈 가중치 모델 ‘Le Chonk’ 공개 — Mistral Large 4(ML4)의 별칭인 1조 파라미터급 프론티어 모델로, 에이전틱 코딩 및 방어적 사이버보안/취약점 분석 워크플로우에 최적화된 오픈 가중치(FP8/NVFP4) 배포 (https://mistral.ai/news/le-chonk-release/)
  • Meta Superintelligence Labs, 초경량 서브에이전트 모델 ‘Muse Ember’ 출시 — 일상적 하위 작업 위임과 빠른 도구 호출 응답성에 최적화된 100만 토큰 컨텍스트 지원 초경량 멀티모달 모델 (https://techcrunch.com/2026/11/09/meta-muse-ember-agent-model/)
  • Anthropic, 고위험 검증 조직 대상 보안·정렬 특화 모델 ‘Claude Mythos 5.2’ 롤아웃 — 일반 공개형 Fable 라인과 달리 사이버보안 취약점 탐지 및 생물학적 정렬 거버넌스 검증을 통과한 엔터프라이즈·정부 파트너 전용 제한적 롤아웃 (https://beevr.ai/news/claude-mythos-5-2-enterprise-rollout)

🛠️ 개발 툴·스킬

  • VS Code 1.146, MCP 네이티브 스킬 및 컨텍스트 인프라 전면 통합 — 외부 래퍼 없이 개발 환경 내부 에이전트 하네스가 MCP 도구와 컨텍스트를 직접 소비하도록 지원하며 레거시 로컬 에이전트 하네스 지원 중단(Deprecated) 발표 (https://visualstudiomagazine.com/articles/2026/11/vscode-mcp-agent-integration.aspx)
  • Mistral Studio, 엔터프라이즈 멀티모달 및 에이전트 파이프라인 트레이싱 강화 — 복수 단계 에이전트 워크플로우를 구축·배포하고 OpenTelemetry 기반 분산 트레이싱으로 실행 경로와 도구 호출을 모니터링할 수 있는 관리 플랫폼 업데이트 (https://mistral.ai/news/mistral-studio-enterprise-workflows/)
  • r/LocalLLaMA, LLVQ(Lattice-based Vector Quantization) 기반 로컬 딥리서치 스택 부상 — 24차원 리치 격자(Leech Lattice) 기반 2비트 극저비트 양자화 모델과 SearXNG를 결합해 독립형 자율 리서치를 로컬 머신에서 구동하는 커뮤니티 파이프라인 논의 (https://reddit.com/r/LocalLLaMA/comments/deep_research_local_agents_llvq/)

📄 논문·트렌드

  • CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation (arXiv:2611.17316) — 지속적으로 변화하는 코드베이스에서 장기 효용 가치와 읽기/쓰기 토큰 비용을 내재화하여 필요한 지점만 선별 보존하는 코딩 에이전트용 메모리 아키텍처 (https://arxiv.org/abs/2611.17316)
  • Classical Energies Learn to Reason 1,000x Faster than Looped Models (arXiv:2611.17309) — 루프형 트랜스포머 대신 고전 홉필드 에너지 함수를 현대화한 CRAM을 통해 제약 조건 논리 추론 학습을 1,000배 빠르게 수행하고 추론 FLOPs를 대폭 절감하는 접근법 제안 (https://arxiv.org/abs/2611.17309)
  • Hacker News 화두: AI 코딩 생산성(2x vs 10x)과 아키텍처 관리 오버헤드 논쟁 — 단순 코드 생성 속도는 향상되었으나 ‘AI Slop’ 검토 및 장기 유지보수 부담으로 실질 처리량 병목이 발생하여, 개발자의 역할이 직접 구현자에서 에이전트 리뷰어·오케스트레이터로 재편되는 현상 집중 논의 (https://news.ycombinator.com/item?id=ai-coding-productivity-realities-2026)

💡 또리팀 적용 포인트

  • CoReMem 방식의 메모리 가치평가(Prospective Valuation) 도입: 장기 세션 진행 시 context.md나 지브레인 노드에 모든 대화와 작업 로그를 단순 적층하지 않고, 재사용 가능성과 토큰 비용을 계산하여 실행 검증 체크포인트 위주로만 영구 메모리에 기록하도록 필터링 로직 개선.
  • 경량 서브에이전트 계층 분기 (Muse Ember 패턴): 메인 오케스트레이터는 종합 계획 수립 및 최종 검증만 전담하고, 파일 전수 검색·단순 문법 치환·린트 수행은 초경량 서브에이전트 모델(Muse Ember 등)로 위임하여 세션 비용 절감과 속도 개선. (※ 대형 프론티어 모델인 Le Chonk는 초경량 서브에이전트 풀에서 제외)
  • 개발 환경 MCP 직결(Direct Harness) 파이프라인: 툴 호출 시 불필요한 중간 래퍼 계층을 줄이고 VS Code 1.146 스타일의 네이티브 MCP 핸들러 구조를 벤치마킹하여 에이전트의 도구 호출 실패율 및 컨텍스트 직렬화 오버헤드 최소화.
