🤖 모델/LLM 소식

  • Gemini 4 Carbon [선별 프리뷰] — 구글이 장기 복합 추론과 사이버보안 방어 워크로드에 특화해 10월 28일 발표한 차세대 플래그십 모델. 현재 정식 전면 릴리스가 아닌 사이버 방어자 대상 선별 프리뷰(Fairwind Program) 단계이며, 개발자 공개 API는 순차 롤아웃 예정 (출처 URL)
  • Claude Haiku 5.5 — 100만 토큰 컨텍스트와 최대 128K 동기 출력 용량, Haiku 라인업 최초의 적응형 추론(Adaptive Thinking 및 effort 파라미터)을 지원하는 경량 모델. 100K 토큰 이하 프롬프트 기준 백만 토큰당 0.10(입력)/0.50(출력)의 저비용 제공 (출처 URL)
  • Mistral Large 4 — 복합 추론과 코드 생성에 특화된 약 1조(1T) 총 파라미터(토큰당 활성 파라미터 약 49B~52B) 규모의 네이티브 멀티모달 Mixture-of-Experts(MoE) 오픈 웨이트 모델 (Le Chonk) 공개 (출처 URL)
  • Kimi K3.1 Pro / Pro Highspeed — 문샷 AI가 100만 토큰 컨텍스트와 프론티어급 에이전트 추론 성능을 지원하는 3T급 오픈 웨이트 모델을 공개. Highspeed 버전은 표준 Pro와 동일한 추론 능력을 유지하며 2~3배 빠른 응답 속도 제공 (출처 URL)

🛠️ 개발 툴·스킬

  • Google Connected Apps via MCP — 서드파티 앱과 외부 도구를 구글 검색 및 Gemini 환경에 직결할 수 있도록 Model Context Protocol(MCP) 서버 등록 및 Android AppFunctions 연동 공식 지원 (출처 URL)
  • AWS Step Functions via AgentCore Gateway (MCP) — 아마존 베드록 에이전트가 관리형 AgentCore Gateway를 통해 기존 API와 AWS Step Functions 워크플로를 MCP 호환 도구로 표준화하여 결정론적 다단계 엔터프라이즈 워크플로를 안전하게 호출 (출처 URL)
  • llm-d 1.0 (CNCF 분산 추론 프레임워크) — Red Hat, IBM Research, Google Cloud, NVIDIA 등이 참여하여 CNCF 샌드박스로 채택된 오픈소스 분산 추론 스택으로, Kubernetes 환경에서 vLLM/SGLang 등을 오케스트레이션하여 KV 캐시 로컬리티와 분산 서빙 비용 최적화 (출처 URL)
  • AI by Zapier (In-Zap Agent Steps) — 기존 독립 에이전트 기능을 코어 Zap 에디터 내 ‘AI by Zapier’ 스텝으로 통합하고, 도구별 세부 승인 게이트(읽기 자동화 및 쓰기 승인 분리)와 Zapier MCP 연동 환경 제공 (출처 URL)

📄 논문·트렌드

  • GitSwarm (arXiv:2610.04862) — 브랜치 가능한 Git 리포지토리를 에이전트 간 공유 메모리로 활용하는 ‘복합 추론(Compounding Inference)’ 체계를 제안하여, ProgramBench 벤치마크 기준 단일 에이전트 베이스라인(65.1%) 대비 다중 에이전트 비동기 협업 성능을 79.4%로 향상시킨 연구 (Meta Superintelligence Labs, Mila 등) (출처 URL)
  • Tencent Hy Memory 2.0 (arXiv:2610.22196) — 텐센트 훈위안이 오픈소스화한 인프라로, 귀속 강화학습(Attributed RL) 기반 전용 메모리 모델(Hy-Memory-30B-A3B)과 MemHub 레이어를 통해 장기 세션 간 정보 추출, 충돌 해소, 이력 진화를 총괄하는 이중 인지 메모리 프레임워크 (출처 URL)
  • NyoomFloat12 (Lossless 12-bit Weight Compression) — BF16 가중치의 지수 구조를 활용한 무손실 12비트 고정 압축 포맷(Float12)과 빠른 디코딩 루틴을 적용해 GPU 메모리 대역폭 병목을 해소하고 LLM 추론 서빙 처리량을 극대화한 기법 (출처 URL)

💡 또리팀 적용 포인트

  • Claude Haiku 5.5를 서브에이전트 라우팅 및 1차 스크리닝 드라이버로 채택: 100K 토큰 이하 프롬프트 기준 0.10(입력)/0.50(출력)의 가성비와 1M 컨텍스트, effort 조절 기능을 활용해 본체 실행 전 대용량 로그 요약이나 단순 파일 탐색 전담 워커로 즉시 분동 가능.
  • GitSwarm 스타일의 다중 에이전트 협업 파이프라인 도입: 단일 CLI 세션에 의존하지 않고 Git 브랜치와 원자적 커밋을 매개로 ‘구현-테스트-코드리뷰’ 역할을 분리한 비동기 복합 추론 루프를 구성해 복잡한 리팩터링 성공률 개선 가능.
  • Tencent Hy Memory 2.0의 Attributed Writer 패턴 벤치마킹: 현재 memory/inbox/outbox 구조에 적용하여 장기 세션 간에 누적되는 작업 맥락과 코드 히스토리의 충돌을 자동으로 해소하고 정밀 보존하는 전용 메모리 관리 모듈 고도화에 적합.
