매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • OpenAI GPT-5.6 시리즈 정식 출시(7/9 예정) — 플래그십 Sol, 미드레인지 Terra, 저비용 Luna 세 모델 라인업이 한 번에 정식 출시된다. (출처)
  • NVIDIA Audex 오디오-텍스트 통합 LLM — ‘Nemotron-Labs-Audex-30B-A3B’, 텍스트 지능을 유지하면서 음성/오디오 생성까지 처리하는 멀티모달 모델. (출처)
  • NVIDIA Nemotron-Labs-TwoTower 오픈 가중치 모델 — 디퓨전 기반, 품질 저하 없이 병렬 텍스트 생성으로 처리 속도 2.42배 향상. (출처)
  • Google TabFM 테이블 전용 제로샷 모델 — 별도 피처 엔지니어링 없이 표 형태 데이터를 바로 분류·회귀 분석하는 특화형 모델. (출처)

🛠️ 개발 툴·스킬

  • Featured / Oshyn 신규 MCP 서버 — GitHub PR 워크플로우 연동(Featured), DXP 도구를 Claude/Cursor에 직접 연동(Oshyn). (출처)
  • Rowboat 로컬 우선 오픈소스 클라이언트 — Claude Desktop 대체 목적, 로컬 호스팅·로컬 데이터 기본 탑재. (출처)
  • Rust 기반 AI 코드 라인 트래킹 Git 확장 — 소스 코드 각 라인을 어떤 에이전트가 작성했는지 Git 히스토리에 영구 추적. (출처)
  • MCP 중앙화 Enterprise-Managed Authorization — 개별 서버 동의 팝업 대신 기업 IDP(OAuth2/OIDC) 연계로 MCP 서버 권한을 일괄 제어. (출처)

📄 논문·트렌드

  • Lilian Weng, Harness Engineering 서베이(7/3) — 계획·툴사용·기억관리 등 베이스 LLM을 감싸는 시스템 구축이 에이전트 자가발전의 지름길임을 규명. (출처)
  • Legible-by-Construction(7/5) — 트랜스포머 FFN·어텐션 레이어를 논리 연산으로 매핑해 성능 저하 없이 완전 해석 가능한 모델로 재구성하는 방법론. (출처)
  • CEO-Bench(7월) — 노이즈·지연이 잦은 500일 모의 창업 환경에서 에이전트의 장기 변수 제어 능력을 측정하는 신규 벤치마크. (출처)
  • arXiv 재단 공식 독립(7/1) — Cornell University 산하 구조에서 벗어나 완전 독립 비영리 법인으로 전환. (출처)

💡 또리팀 적용 포인트

  • Harness Engineering 서베이(Lilian Weng): CLAUDE.md가 이미 하고 있는 “Planning-Memory-Tool Calling 인터페이스 명시화” 방향이 최신 연구와 정확히 일치 — 특히 Self-Harness(자가 보정 루프) 섹션을 이 프레임으로 재검토하면 보강 포인트 찾기 좋음.
  • Rust Git AI Line Tracker: 파생봇(클또리 spawn 에이전트)이 코드를 여러 개 동시에 작성할 때, 어떤 봇/버전이 어느 라인을 썼는지 추적하는 아이디어 — G-Brain의 “Git ↔ 지식 연결”(G2) 원칙 확장에 참고할 만함.
  • MCP Enterprise-Managed Authorization: 지금은 개별 MCP 서버(vault, context7 등)마다 권한 승인을 받는 구조인데, 서버 개수가 늘면 중앙화된 권한 관리 패턴을 검토할 시점이 올 수 있음 (지금 당장 급하진 않음).
