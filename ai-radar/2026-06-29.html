AI 레이더 2026-06-29

2026년 6월 29일6 min read

  • ai-radar

매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • GPT-5.6 Sol (Preview) — OpenAI가 Reasoning 성능을 대폭 강화한 최신 모델 프리뷰를 공개했으며, 서브에이전트 조율을 통해 복잡한 워크플로우를 해결하는 ‘Ultra Mode’를 도입하고 코딩 벤치마크(Terminal-Bench 2.1)에서 최고점을 기록했습니다. (OpenAI)
  • GPT-5.5-Cyber — OpenAI가 사이버 보안에 특화되어 CyberGym 벤치마크 85.6%를 달성한 정부 및 검증 팀 전용 보안 에이전트 모델을 공식 출시했습니다. (Unrot)
  • Claude Mythos (Preview) — Anthropic이 최고 수준의 추론 성능(Reasoning score 72.5)을 보이는 차세대 고성능 모델 ‘Mythos’의 프리뷰 버전을 공개했습니다. (Punku)
  • MiniMax M3 — 100만 토큰 컨텍스트 윈도우와 네이티브 멀티모달(비디오/컴퓨터 사용) 기능을 제공하는 오픈 가중치 모델로, SWE-Bench Pro에서 59.0%의 정답률을 보이며 상용 API 수준에 도달했습니다. (Kilo)

🛠️ 개발 툴·스킬

  • OpenAI Secure MCP Tunnel — OpenAI가 자사의 호스트 제품군과 격리된 사설 네트워크 내 MCP 서버를 인터넷 노출 없이 안전하게 연결해 주는 터널링 솔루션을 공개했습니다. (OpenAI)
  • MCP Stateless Architecture — 핵심 Model Context Protocol(MCP) 사양이 7월 28일 정식 발표를 목표로 무상태(Stateless) 구조의 릴리즈 캔디데이트(RC) 단계를 밟고 있어, 서버 인스턴스 확장성과 UI 렌더링 성능이 비약적으로 개선될 예정입니다. (YouTube)
  • Stibo Systems MCP Server — AI 에이전트가 지배적이고 관리된 마스터 데이터에 안전하게 액세스할 수 있도록 돕는 엔터프라이즈급 공식 MCP 서버가 공개되었습니다. (Yahoo)

📄 논문·트렌드

  • AI 에이전트 보안 위협 (Agent Jacking) — CISA를 포함한 유수 보안 기관들이 AI 에이전트 도구를 노리는 프롬프트 인젝션 기반의 신종 위협 ‘Agent Jacking’과 맥OS 타겟 ‘Gaslight’ 공격 기법에 대한 연구 및 권고안을 잇따라 발표했습니다. (TheHackerNews)
  • 상용 API에서 오픈 가중치 모델(Open-weight)로의 이동 — 비용 효율성(ROI)과 데이터 프라이버시가 핵심 화두가 됨에 따라 많은 빌더들이 상용 API 대신 DeepSeek V4나 MiniMax M3 같은 강력한 오픈 가중치 모델로 이전하는 추세가 강화되고 있습니다. (Mean CEO)
  • AI 생성 코드의 부채와 품질 논란 — 해커뉴스 커뮤니티에서 단순 코딩 어시스턴트가 쏟아내는 정돈되지 않은 코드(Mess)에 대한 불만이 증가하며, 보안성과 지속 유지 가능성을 고려한 설계 원칙이 재조명되고 있습니다. (Mean CEO)

💡 또리팀 적용 포인트

  • 또리 협업 환경의 MCP Stateless 선제 검토: 다가오는 7월 28일 사양 전환에 발맞춰 우리 protect-mcp 및 사용자 정의 툴들이 세션 상태를 저장하지 않고도 정상 동작하도록 아키텍처 설계를 선제 검토합니다.
  • Agent Jacking 위협 방어 필터 적용: CLI 및 에이전트 오케스트레이션 환경에서 유입될 수 있는 악성 프롬프트 인젝션을 차단하기 위해, 실행 경로 및 파일 시스템에 접근하기 전에 프롬프트를 전처리하는 검증 단계를 추가해야 합니다.
  • GPT-5.6 Sol의 Subagent “Ultra Mode” 흐름 벤치마킹: 클또리, 젬또리, 챗또리 3형제가 작업 단위를 세분화하여 병렬로 해결한 뒤 결과를 종합하는 조율 규칙을 고도화하는 데 GPT-5.6의 에이전트 오케스트레이션 구조를 벤치마킹합니다.
