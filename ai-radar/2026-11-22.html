🤖 모델/LLM 소식

  • Google ‘Gemini 4 Neon’ 릴리스 — 100만 토큰 컨텍스트와 4단계 가변 추론 깊이(thinking levels)를 지원하며, 실시간 AI 코딩·에이전트 하네스 및 엔터프라이즈·과학 연구 추론 속도를 최적화한 최신 모델 공개 (https://blog.google/technology/ai/gemini-4-neon-update/)
  • Microsoft ‘MAI Cyber 2 Flash’ 보안 특화 모델 배포 — 100만 토큰 컨텍스트 윈도우를 지원하며, CyberGym-E2E 벤치마크 기반 엔터프라이즈 사이버 위협 진단 및 취약점 분석에 최적화된 마이크로소프트 보안 생태계 전용 모델 공개 (https://microsoft.ai/news/mai-cyber-2-flash-release/)
  • Anthropic ‘Claude Opus 5’ 및 ‘Fable 5.2’ 벤치마크 갱신 [루머/미검증] — SWE-bench Verified 코딩 및 초장기 에이전틱 작업 성능을 최고 수준으로 끌어올린 차세대 라인업 (https://userightai.com/claude-5-opus-benchmark-update/)

🛠️ 개발 툴·스킬

  • Claude Code CLI 백그라운드 서브에이전트 제어 기능 [루머/미검증] — 장시간 백그라운드 루프 실행 및 자동 차트·시각화 생성을 지원하는 터미널 에이전트 업데이트 (https://news.ycombinator.com/item?id=42201948)
  • 에이전트 전용 상태 관리 엔진(State Management Infrastructure) 담론 [루머/미검증] — 단순 프롬프트 주입을 탈피하여 신념 갱신(belief update) 및 메모리 감쇠를 처리하는 상태 관리 계층 도입 논의 (https://news.ycombinator.com/item?id=42210834)
  • FlowHunt & Gumloop 엔터프라이즈 멀티에이전트 오케스트레이터 — 노코드/로우코드 기반으로 복잡한 비즈니스 로직과 분산 에이전트 파이프라인을 연동·관리하는 엔터프라이즈 워크플로우 자동화 도구 부상 (https://flowhunt.io/blog/enterprise-multi-agent-systems-2026/)

📄 논문·트렌드

  • TokenEconomizer: Experience-Driven Black-Box Cost Control for Coding Agents — 모델 가중치나 에이전트 내부 코드 수정 없이, 미사용 도구 프루닝과 마이크로 스킬 주입 및 실패 루프 차단을 통해 코딩 에이전트의 토큰 비용을 선제 절감하는 연구 (https://arxiv.org/abs/2611.14290)
  • Gamer: A Generalist Vision-Language-Action Foundation Model — 희소 사고(Sparse-thinking)와 시간 인식형 강화학습(TA-GRPO)을 결합하여 화면 픽셀 관측 및 키보드·마우스 조작으로 복잡한 실시간 3D 환경을 장기 제어하는 범용 VLA 모델 (https://huggingface.co/papers/2611.12984)
  • From Weeks to Hours: Fast and Principled SFT Data Generation for Reasoning LLMs — 로컬 손실 기하학 기반의 SFTProbe 기법을 통해 추론형 대형 언어 모델 부트스트래핑을 위한 고품질 SFT 합성 데이터 큐레이션 시간을 대폭 단축한 방법론 (https://arxiv.org/abs/2611.11543)

💡 또리팀 적용 포인트

  • TokenEconomizer 기반 툴 루프 인터셉터 도입: 젬또리/클또리 오케스트레이터에서 동일 툴 호출 실패나 무한 리트라이 발생 시, 불필요한 도구를 동적 프루닝(Pruning)하고 마이크로 스킬을 즉시 주입하여 컨텍스트 낭비와 토큰 비용을 능동적으로 방지.
  • 에이전트 신념 갱신(Belief Update) 및 메모리 감쇠 엔진 적용: 매 세션 전체 컨텍스트와 outbox/inbox 로그를 그대로 누적 주입하는 대신, 완료된 과거 세션 기록은 감쇠시키고 핵심 결정 상태만 갱신하는 상태 관리 파이프라인 구축.
  • CLI 비동기 백그라운드 서브에이전트 큐 강화: Claude Code 스타일의 비동기 백그라운드 작업 루프를 적용하여, 시간 소모가 큰 다중 검색 및 팩트체크 리서치를 백그라운드에서 병렬 처리하고 메인 턴은 블로킹 없이 유지.
