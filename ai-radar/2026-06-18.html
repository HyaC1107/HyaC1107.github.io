AI 레이더 2026-06-18

2026년 6월 18일4 min read

  • ai-radar

매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • Claude Opus 4.8 — 앤트로픽 최신 플래그십, 코딩·에이전트 워크플로우 벤치마크 최정상 기록 (22software.com)
  • MAI-Thinking-1 — MS Build 2026 발표, SW 엔지니어링·수학 논리 특화 마이크로소프트 자체 추론 모델 (microsoft.ai)
  • Granite 4.1 8B — IBM 오픈웨이트 소형 모델, 코딩·기업 RAG 벤치마크에서 높은 비용 효율성 입증 (labellerr.com)

🛠️ 개발 툴·스킬

  • Docker Open-Source MCP Gateway — MCP 서버 연동 중앙 중계 + 인증/RBAC/보안 정책 적용 오픈소스 게이트웨이 (docker.com)
  • WitnessAI Agentic Control — 운영 환경 AI 에이전트의 MCP 서버 접근 모니터링·거버넌스·감사 플랫폼 (helpnetsecurity.com)
  • protect-mcp — MCP 서버에 도구 단위 실행 정책·Rate Limiting·서명 감사로그 추가하는 보안 래퍼 라이브러리 (news.ycombinator.com)

📄 논문·트렌드

  • Fixed-Point Reasoners — 루핑 트랜스포머 안정화로 Test-Time Compute 단계 반복 추론 확장 연구 (arxiv.org)
  • Arbor — 전략적 조율·고립 가설 테스트·영구 지식 트리로 에이전트 자율 과학 연구 지원 프레임워크 (huggingface.co)
  • EvolveNav — 사전성찰(preflection) + 자가 진화 메모리로 제로샷 물리 환경 탐색 강화 (arxiv.org)
  • DRFLOW — 에이전트 장기 과제 계획·개인화 워크플로우 예측 능력 측정 딥리서치 벤치마크 (arxiv.org)

💡 또리팀 적용 포인트

  • 하이브리드 라우팅: 단순 질의는 Granite 4.1 8B(로컬), 고난도 코딩은 Claude Opus 4.8로 동적 라우팅 — 비용 최적화 설계 힌트
  • MCP 보안: Docker MCP Gateway + protect-mcp 패턴 → 또리삼형제 오케스트레이터에 도구 단위 권한 레이어 구축 참고
  • 자가 진화 메모리: Arbor·EvolveNav의 영구 지식 트리 → 클또리 memory/ 시스템을 “실패 원인 + 보정 이력” 트리로 발전시키는 방향 검토 가능

젬또리(Antigravity CLI agy —model flash + 실시간 웹 검색) 리서치 · 클또리 정리
