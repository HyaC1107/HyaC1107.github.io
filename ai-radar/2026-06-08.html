매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • Claude Opus 4.8 출시 — 최대 1,000개 서브 에이전트 병렬 실행하는 ‘동적 워크플로우’ 탑재, 벤치마크 1위 (출처)
  • OpenAI GPT-5.6 티징 — 인간 개입 최소화한 에이전트 워크플로우 최적화 모델, 6월 말 출시 예정 (출처)
  • Google Gemini 3.5 Pro 배포 시작 — 100만 토큰 이상 긴 문맥 추론 + 멀티모달 강화, 이번 달 정식 배포 (출처)

🛠️ 개발 툴·스킬

  • MCP 2.0 대규모 개편 — HTML UI 반환 + 장기 비동기 작업(Tasks Extension) 지원 추가 (출처)
  • Hugging Face smolagents — JSON 호출 대신 파이썬 코드 직접 작성·실행하는 ‘Code-first’ 에이전트 방식 확산 중 (출처)
  • Arena ‘Agent Mode’ 샌드박스 출시 — 자율형 에이전트 다단계 워크플로우 벤치마킹 + 안전 테스트 환경 (출처)

📄 논문·트렌드

  • Mixture-of-Agents (MoA) — 저비용 전문 모델 다수 조합 라우팅이 GPT-4 단일 모델보다 비용 대비 성능 우월 (출처)
  • Self-Debugging Production Code (DeepMind) — 에이전트가 테스트 통과까지 스스로 코드 수정, 94% 성공률 기록 (출처)
  • Semantic KV Store 메모리 — RAG 대비 회상률 40% 향상, 에이전트 장기 기억을 의미론적 Key-Value로 관리 (출처)

💡 또리팀 적용 포인트

  • MoA로 비용 절감 — 클또리(고비용) 대신 젬또리 Flash 여러 개 조합 오케스트레이션으로 정확도 유지하며 비용 절감 가능
  • MCP 2.0 Tasks Extension — 우리 ttori-tools MCP 서버에 장기 실행 작업 상태관리 표준화 적용 검토 가치 있음
  • Semantic KV Store 메모리 — 현재 memory/ 폴더 방식에서 의미론적 KV 저장소로 고도화하면 세션 간 맥락 인지 크게 개선 가능
