매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • Claude Mythos (Oceanus) 리크 — 10T 파라미터 규모, Minecraft 등 복잡한 게임을 원샷 코딩 가능한 차세대 모델 정보 유출 (codingmerchant.com)
  • OpenAI GPT-5.6 ‘kindle-alpha’ — 추론 극대화 비공개 모델 체크포인트 확인, 6월 30일 공식 출시 유력 (windowsforum.com)
  • JetBrains Mellum2 — 디버깅·코드 생성 특화 12B MoE 모델, IDE 내 통합 출시 (devflokers.com)

🛠️ 개발 툴·스킬

  • Holo3.1 (Hcompany) — 클라우드 API 없이 로컬에서 마우스/키보드·GUI 제어하는 초고속 컴퓨터 유즈 에이전트 (dev.to)
  • GitHub Agent HQ — Anthropic·OpenAI 등 멀티 벤더 에이전트를 단일 워크플로우로 통합 관리하는 거버넌스 플랫폼 (securityboulevard.com)
  • Hermes Agent (Nous Research) — 성공한 작업 결과를 재사용 가능한 스킬로 스스로 변환하는 오픈소스 자가 개선 에이전트 (lushbinary.com)

📄 논문·트렌드

  • Self-Revising Discovery Systems (MIT) — 범주론(Category Theory)으로 AI가 자신의 지식 구조를 동적으로 재구성하는 시스템 (medium.com)
  • Learn From Your Own Latents (EPFL) — 텍스트 토큰 대신 내부 잠재 표현을 예측해 학습 효율을 비약적으로 향상시키는 연구 (medium.com)
  • Enterprise Time Bomb (GeekNews) — 자율 에이전트의 폭발적 토큰 소모로 인한 기업 비용 리스크 대두, 비용 관리 중요성 급부상

💡 또리팀 적용 포인트

  • Hermes Agent 스킬 자가 생성 패턴 — 성공한 워크플로우를 재사용 스킬로 변환하는 구조는 클또리 스킬 시스템에 직접 응용 가능. 반복 작업 패턴을 .claude/skills/에 자동 추가하는 방식 검토
  • GitHub Agent HQ의 멀티벤더 거버넌스 — 클또리·젬또리·챗또리 오케스트레이터와 유사 구조. 에이전트별 역할 분리 + 단일 워크플로우 통합이 우리 팀 방향과 일치, 설계 참고할 것
  • Enterprise Time Bomb 경고 — 젬또리 리서치 호출 시 토큰 폭증 주의. 현재 -m flash 사용 중인 건 비용 최적화 측면에서 올바른 선택

젬또리(-m flash + 실시간 구글 검색) 리서치 · 클또리 정리 · 그라운딩 검증 통과
