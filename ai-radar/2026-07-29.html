AI 레이더 2026-07-29

매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 자동 생성 (Windows 작업 스케줄러 ttori-ai-radar, 매일 08:00 · 젬또리 agy Gemini 3.5 Flash (Medium)). 클또리 검수를 거치지 않은 원문이다. [미검증] 태그가 붙었거나 출처가 도메인 홈페이지뿐인 항목은 채택 전 반드시 원문 확인할 것. flash가 학습데이터를 최신 정보로 착각해 내놓는 경우가 있다.

🤖 모델/LLM 소식

  • GPT-5.6 [미검증] — OpenAI가 Sol(플래그십), Terra(균형), Luna(경량) 3가지 성능 등급으로 105만 토큰 컨텍스트 및 개선된 프롬프트 캐싱을 지원하는 신규 모델 제품군을 공식 출시했습니다. (출처 URL)
  • Gemini 3.6 Flash [미검증] — 구글이 기존 3.5 Flash 대비 코딩 및 지식 작업 성능을 개선하면서 출력 토큰 사용량을 약 17% 절약할 수 있는 고효율 모델을 발표했습니다. (출처 URL)
  • Claude Opus 5 [미검증] — 앤트로픽에서 에이전틱 코딩과 장기 추론 능력을 극대화하고 자가 검증 기능을 탑재한 새 플래그십 모델을 기존 Opus 요금 수준으로 제공하기 시작했습니다. (출처 URL)

🛠️ 개발 툴·스킬

  • Model Context Protocol (MCP) 2026-07-28 스펙 업데이트 [미검증] — 세션 핸드셰이크를 없애 무상태(Stateless) 아키텍처로 전면 개편하고, MCP Apps 및 Tasks를 지원하는 공식 확장 프레임워크가 도입되었습니다. (출처 URL)
  • ChatGPT Work [미검증] — OpenAI가 복잡한 다단계 프로젝트 수행을 위해 다양한 앱과 워크플로우 전반의 컨텍스트를 연동하고 처리할 수 있는 에이전틱 작업 도구를 공개했습니다. (출처 URL)
  • Comet [미검증] — 퍼플렉시티가 자사 Max 구독자들을 대상으로 검색, 웹 브라우징, AI 어시스턴트를 일체형으로 통합한 AI 웹 브라우저를 출시했습니다. (출처 URL)

📄 논문·트렌드

  • Verbalizable Representations Form a Global Workspace in Language Models [미검증] — Anthropic 연구진이 LLM이 내부 추론 과정에서 인간 인지의 ‘글로벌 작업 공간(Global Workspace)‘과 유사하게 특정 중요 표상들을 유지하며 활용하는 메커니즘을 분석했습니다. (출처 URL)
  • Mnemosyne (arXiv:2607.00269) [미검증] — AI에 의해 자동 생성된 워크플로우를 실시간으로 검증하고 에러 발생 시 자가 복구(Self-Repair)할 수 있도록 돕는 에이전틱 트랜잭션 처리 기법 연구입니다. (출처 URL)
  • SovereignNegotiation-Bench (arXiv:2607.02814) [미검증] — 개인정보 보호와 명시적 위임 동의를 고려하면서 사용자 대리 에이전트 간의 자율 협상 능력을 종합 평가하는 벤치마크를 제안했습니다. (출처 URL)

💡 또리팀 적용 포인트

  • Model Context Protocol (MCP) 무상태(Stateless) 규격 및 Tasks 확장 도입: CLI 오케스트레이터의 단발성 실행 환경 특성상 상태를 유지해야 하는 기존 세션 방식은 관리 부담이 큽니다. 무상태 설계를 차용하여 매 실행 시 메타데이터를 넘겨 처리하도록 구조를 간소화하고, 비동기 장기 실행 작업을 위해 Tasks 확장 표준을 반영하면 높은 확장성을 확보할 수 있습니다.
  • Gemini 3.6 Flash / Claude Opus 5의 하이브리드 라우팅 적용: 비교적 가볍거나 빠른 응답이 필요한 CLI 라우팅 및 단순 도구 호출 단계에는 출력 토큰이 최적화된 Gemini 3.6 Flash를 배치하고, 고난도의 코드 리팩터링 및 자가 검증 단계에는 Claude Opus 5를 매핑함으로써 최적의 비용 대비 성능을 이끌어낼 수 있습니다.
  • Mnemosyne의 자가 복구(Self-Repair) 워크플로우 패턴 설계: CLI 오케스트레이터 내에서 다단계 코드 생성 및 실행 명령들이 실패할 경우 전체 프로세스가 붕괴되는 현상을 막기 위해, 트랜잭션 단위의 실행 결과 검증 및 롤백/수정 피드백 루프를 핵심 에이전트 실행 엔진에 적용할 수 있습니다.
