매일 아침 자동 생성되는 AI 소식 다이제스트입니다. 젬또리(Gemini)가 웹을 검색해 정리하고 검수봇이 사실 확인을 거칩니다. [미검증] 표시가 있거나 출처가 홈페이지뿐인 항목은 원문을 확인하세요.

🤖 모델/LLM 소식

  • DiffusionGemma 26B-A4B — Google이 6/9 오픈소스 출시. 텍스트 확산(Diffusion) 방식으로 자기회귀 대비 4배 빠른 생성 속도. (deepmind.google)
  • NVIDIA Nemotron 3 Ultra — 5500억 파라미터, 완전 오픈 라이선스로 6/4 공개. OCI Enterprise AI에서 즉시 사용 가능. (nvidia.com)
  • Qwen 3.5-27B — r/LocalLLaMA에서 싱글 GPU 최적 ‘Workhorse’ 모델로 선정. 효율·성능 모두 극찬. (reddit.com/r/LocalLLaMA)
  • OpenAI Dreaming V3 — ‘시간적 인지(Temporal Awareness)’ 기능으로 수년간 대화 맥락을 자동 요약하여 일관된 페르소나 유지. (medium.com)

🛠️ 개발 툴·스킬

  • Microsoft Scout — M365(Teams, Outlook 등) 전반을 자율 오케스트레이션하는 상시 가동형 에이전트, 6/5 출시. (augusto.digital)
  • Google Managed Agents API — 샌드박스 리눅스 환경 즉시 프로비저닝. 에이전트가 안전하게 코드 실행·웹 탐색 가능한 인프라. (augusto.digital)
  • Lasso Security MCP Gateway — 오픈소스 MCP 보안 게이트웨이. MCP 상호작용에 거버넌스·모니터링·보안 제어 레이어 추가. (lasso.security)
  • Microsoft Work IQ API — 6/16 출시 예정. 일반 MCP 도구 + 시맨틱 인덱스 기능 제공. Copilot Studio와 연동. (microsoft.com)

📄 논문·트렌드

  • LCLMs (Latent Context Language Models) — NYU·Columbia 연구팀. LLM 입력 컨텍스트 16배 압축, 정확도 손실 없이 8.8배 속도 향상. (huggingface.co)
  • Agents’ Last Exam (ALE) — UC Berkeley, 1,000+ 실제 경제적 가치 창출 과업 기반 에이전트 벤치마크. 챗봇 vs 실무 에이전트 격차 수치화. (huggingface.co)
  • “Toronto Worm” 보안 경고 — 클라우드 API 없이 로컬 LLM만으로 네트워크 취약점을 자율 공격하는 AI 웜 PoC. Hacker News 논란. (latent.space)
  • AI 연구 시스템 중심 전환 — 2026 트렌드: 모델 혁신 → 시스템 수준 배포·거버넌스·인간-AI 협업으로 이동. NeurIPS 2026 AI 생성 논문 18.4% 거부. (neurips.cc)

💡 또리팀 적용 포인트

  • MCP Gateway 패턴 참고: Lasso Security MCP Gateway처럼, 또리삼형제 오케스트레이터에 MCP 호출 로깅·보안 레이어 추가 검토 가능.
  • Temporal Memory 구조 벤치마킹: OpenAI Dreaming V3의 “핵심 컨텍스트 자동 추출→페르소나 유지” 방식을 context.md + memory/ 자동 갱신 루틴에 적용.
  • Self-Correction 루프 강화: Google Managed Agents처럼, 클또리 오케스트레이터가 코드 실행 결과(stdout/err)를 자동 분석 후 수정하는 루프 도입.
