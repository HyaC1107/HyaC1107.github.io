🤖 모델/LLM 소식

  • Gemini Omni 1.2 Flash — 대사 및 음향 효과를 네이티브로 포함하는 최대 15초 비디오 생성, 다중 레퍼런스 이미지 기반 캐릭터 일관성 유지, 자연어 기반 대화형 비디오 편집을 지원하며 생성 비용을 기존 대비 30% 절감(초당 약 $0.07)한 멀티모달 모델 정식 출시 (https://felloai.com/gemini-omni-1-2-flash-release)
  • OpenAI GPT-6 Sol & Luna — 플래그십 Astra 아키텍처를 계승하여 API 단가를 대폭 인하하고 실무 워크플로우에 최적화한 다운마켓 파생 모델 공개; 코딩 및 에이전트 특화로 사실 오류율을 낮추고 reasoning.effort 조절을 지원하는 ‘Sol’과 대용량 반복 작업용 초저비용·초고속 경량 모델 ‘Luna’로 구성 (https://sefaaydin.com/openai-gpt-6-sol-luna-developer-update)
  • Moonshot AI Kimi K3.1 Pro — 총 2.8조 파라미터(활성 1,040억 개) 규모의 MoE 구조와 100만 토큰 컨텍스트 창을 갖추고, Gated DSA(희소 어텐션) 메커니즘을 적용해 장기 에이전트 코딩 및 멀티모달 분석 벤치마크를 갱신한 오픈 웨이트 플래그십 모델 공개 (https://felloai.com/kimi-k3-1-pro-open-weights-benchmark)
  • Mistral Large 4 — 약 1조 파라미터(활성 520억 개) MoE 기반 멀티모달 플래그십 모델로, 별도 추론 라인업을 단일 모델로 통합하여 작업 난이도에 따라 reasoning_effort(low/medium/high) 조절 및 명시적 [THINK] 추론 트레이스 출력을 지원하는 오픈 가중치 모델 출시 (https://universeblend.blog/mistral-large-4-thinking-mode)

🛠️ 개발 툴·스킬

  • Perplexity “Teammates” — Perplexity Computer 기반으로 독립된 데스크톱·브라우저 샌드박스에서 장기 목표(Ongoing Project)를 위임받아 다중 백그라운드 에이전트 병렬 스폰, Slack·GitHub 실시간 모니터링 및 상호 협업을 자율 수행하는 엔터프라이즈 에이전트 기능 공개 (https://pulse2.com/perplexity-computer-launches-teammates-for-enterprise-workflows)
  • JetBrains 개발자 생태계 리포트: 터미널 코딩 에이전트 전환 가속 — 단순 인라인 코드 어시스턴트를 넘어 터미널·CLI 기반 자율 코딩 에이전트(Claude Code 등) 도입이 가속화됨에 따라, IDE와 에이전트를 연결하는 오픈 표준 Agent Client Protocol(ACP) 및 JetBrains Air Gateway 제어 평면 통합이 확산 중이라는 조사 결과 발표 (https://jetbrains.com/research/devecosystem-2026-ai-agents)
  • IBM TechXchange 자율 에이전트 거버넌스 프레임워크 — HashiCorp Vault 연동 암호화 에이전트 식별자 발급, 최소 권한 단기 자격증명, watsonx Orchestrate 기반 멀티클라우드(AWS Bedrock, Azure Foundry, Google Gemini 등) 에이전트 탐색·격리 킬스위치, 도구 호출 프로세스 감사 체계를 결합한 엔터프라이즈 보안 아키텍처 공개 (https://ibm.com/blog/agent-identity-governance-framework-techxchange)

📄 논문·트렌드

  • DeepAnalyze: 자율 데이터 사이언스 파이프라인 프레임워크 — 다중 에이전트 간 역할 분담과 실행 코드 디버깅 루프를 결합하여 데이터 탐색·전처리부터 머신러닝 파이프라인 구축까지 엔드투엔드로 자율 수행하는 아키텍처 제안 (https://medium.com/ai-research-trends/deepanalyze-autonomous-data-science-agents)
  • Recursive & Environment-Based LLM 아키텍처 연구 — 거대 컨텍스트 창에 전체 정보를 선형 주입하는 한계를 극복하기 위해, 외부 파일 시스템 및 도구를 상호작용 환경으로 간주하고 세부 단위 서브에이전트를 재귀 호출하여 초장문맥을 제어하는 구조 동향 (https://medium.com/ai-papers-daily/recursive-environment-llm-token-scaling)
  • Test-Time Compute 기반 MCTS 탐색 전략 고도화 — 모델 파라미터 사전 학습 스케일링의 한계를 보완하기 위해, 검증기(PRM)와 결합된 몬테카를로 트리 탐색(MCTS) 및 추론 단계 연산량(Test-Time Compute) 확장을 통해 고난도 수학·코딩 추론 성공률을 극대화하는 연구 급증 (https://aipapersacademy.com/test-time-compute-mcts-scaling-trends)

💡 또리팀 적용 포인트

  • 동적 Reasoning Effort 분기(GPT-6 Sol / Mistral Large 4 패턴): 오케스트레이터의 라우터 단계에서 단순 포맷팅이나 린팅은 경량·제로 추론 모드로 즉시 처리하고, 아키텍처 설계 및 다중 파일 교정 작업에는 고추론(reasoning_effort=high) 모드를 동적 분기하여 API 토큰 비용 절감과 처리 정확도를 동시 확보.
  • 컨텍스트 환경화 및 재귀 호출 구조(Recursive LLM 연구): CLI 오케스트레이터에서 거대 컨텍스트를 단일 프롬프트에 통째로 누적하지 않고, 파일 시스템을 환경 상태(State)로 취급하며 하위 서브에이전트를 재귀 스폰(Subagent Spawning)해 문맥 창 오염과 토큰 낭비를 원천 방지.
  • 에이전트 권한 및 시크릿 접근 감사 가드레일(IBM 거버넌스 프레임워크): 양방향 우체통 비동기 작업 시 각 서브에이전트가 실행 가능한 CLI 명령어와 민감 환경변수 접근 범위를 세션 단위 최소 권한으로 격리하고, 실행 감사 로그를 남겨 자동화 루프 도중 발생할 수 있는 시스템 오작동 차단.
