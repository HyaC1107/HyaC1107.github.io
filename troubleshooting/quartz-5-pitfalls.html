Quartz 5로 옵시디언 블로그 만들며 밟은 함정 8가지

2026년 9월 11일7 min read

  • 삽질노트
  • quartz
  • obsidian
  • 블로그

옵시디언 볼트 일부를 그대로 웹으로 내보내는 Quartz 5를 이틀 써보고 밟은 것들입니다. 전부 직접 밟았고, 해결책은 실제로 돌아간 것만 적습니다. 결과물은 이 블로그입니다.

1. 모든 글 제목이 “제목 없음”이 된다

증상: 빌드는 되는데 페이지마다 제목이 “제목 없음”, 본문 맨 위에 frontmatter가 그대로 노출. 원인: Quartz 5는 frontmatter 파싱을 note-properties 플러그인이 맡는다. “속성 박스 안 보이게 하려고” 이 플러그인을 통째로 껐더니 파싱 자체가 사라졌다. 해결: 플러그인은 켜 두고 hidePropertiesView: true로 박스만 숨긴다. order는 다른 플러그인보다 앞(5)에.

2. 닫는 --- 바로 뒤에 본문을 붙이면 frontmatter가 아니다

증상: 스크립트로 생성한 글만 제목이 앵커 링크로 새어나감. 원인: ---\n본문 처럼 빈 줄 없이 붙이면 YAML 블록으로 인식하지 않는다. 해결: 닫는 --- 다음에 빈 줄 하나.

3. 한글 주소 페이지에서 그래프 뷰가 점 하나만 그린다

증상: 링크가 분명히 있는데 한글 파일명 글에서만 그래프에 자기 자신만 뜸. 영문 파일명 글은 정상. 원인: 그래프 스크립트가 현재 페이지 slug를 location.pathname에서 읽는데 디코딩을 안 한다. %EC%97%90... 상태로 인덱스를 찾으니 못 찾는다. 해결: 파일명을 영문 슬러그로(제목은 frontmatter title에 한글로). 옛 한글 주소는 aliases:로 리다이렉트.

4. 글을 열면 페이지가 900px 아래로 내려가 있다

증상: 글 페이지 진입 직후 제목이 화면 위로 사라지고 중간부터 보임. 헤드리스 브라우저로 재면 scrollY=888. 원인: 탐색기(Explorer)가 현재 글 항목을 scrollIntoView() 하는데, 목록이 사이드바보다 길면 브라우저가 창 전체를 스크롤한다. 해결: 왼쪽 사이드바를 position: sticky 대신 position: fixed로. fixed 조상 안의 요소는 창 스크롤 대상에서 빠진다. 사이드바가 그리드 흐름에서 빠지므로 본문 .center에 grid-column: 2; grid-row: 1을 명시해야 한다(안 하면 본문이 1열로 밀려 들어간다).

5. 폰트 플러그인은 body에 문자열을 주면 링크가 400이 난다

증상: Google Fonts 요청이 400, 폰트 전부 폴백. 원인: quartz-fonts 플러그인은 body에 준 값을 그대로 family=에 넣는다. "Pretendard", sans-serif 같은 폰트 스택을 주면 그게 Google에 그대로 날아간다. 그리고 Google 링크에 들어가는 슬롯은 header/body/code/title 뿐이라 interface나 h6에 넣은 폰트는 로드되지 않는다. 해결: 셀프호스팅 폰트(Pretendard)는 custom.scss에서 @font-face로, Google 폰트 하나를 더 싣고 싶으면 title 슬롯을 빌린다(사이트 제목 폰트는 CSS로 다시 덮으면 됨).

6. 로컬에서 python -m http.server로 열면 그래프가 안 뜬다

증상: 로컬 확인용으로 public/을 정적 서버로 띄우고 /글.html을 열면 3번과 같은 증상. 원인: 진짜 배포 주소는 /글인데 로컬은 .html이 붙어서 slug가 안 맞는다. 버그가 아니라 테스트 방법 문제. 해결: 확장자 없는 주소로 서빙하는 서버(npx quartz build --serve)를 쓰거나, 라이브 주소로 확인한다.

7. 최근 글 목록에 폴더 인덱스가 섞인다

증상: “최근 글”에 홈·폴더 페이지가 글처럼 뜸. 원인: RecentNotes 플러그인에 YAML로 줄 수 있는 filter 옵션이 없다(TS 오버라이드만). 해결: 인덱스 링크는 /로 끝나므로 CSS 한 줄 — li:has(> .section > .desc > h3 > a[href$="/"]) { display: none }.

8. npm 9에서는 설치가 안 된다

증상: npm install에서 EBADENGINE. 원인: Quartz 5는 Node 22 이상, npm 10.9.2 이상을 요구한다. 해결: npm install -g npm@latest. 전역 npm이 바뀌니 다른 프로젝트 영향은 한 번 확인.

정리하면, Quartz 5는 frontmatter 파서가 플러그인이고, URL을 디코딩 없이 쓰는 곳이 있으며, 폰트 플러그인이 Google 링크를 순진하게 만든다는 세 가지만 알고 시작하면 하루가 덜 걸립니다. 커스텀 CSS는 컴포넌트 스타일이 @layer quartz-base 안에 있어서 !important 없이 전부 덮어씁니다 — 이건 좋았습니다.
