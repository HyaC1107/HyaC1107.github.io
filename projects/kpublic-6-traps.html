공공데이터포털 API 함정 6가지 — SERVICE_KEY_IS_NOT_REGISTERED_ERROR부터 기상청 격자까지

공공데이터포털 API 함정 6가지 — SERVICE_KEY_IS_NOT_REGISTERED_ERROR부터 기상청 격자까지

공공데이터포털(data.go.kr) API를 파이썬으로 붙이면서 밟은 함정들을 정리합니다. 전부 직접 밟았고, 마지막에 이걸 한 번에 처리하려고 만든 라이브러리(kpublic)를 소개합니다.

1. SERVICE_KEY_IS_NOT_REGISTERED_ERROR — 키는 맞는데 등록이 안 됐다고 한다

가장 많이 밟는 함정입니다. 포털 마이페이지는 같은 키를 두 형태로 보여줍니다.

예
일반 인증키 (Decoding)abc+DEF/ghi==
일반 인증키 (Encoding)abc%2BDEF%2Fghi%3D%3D

Encoding 키를 requests의 params에 넣으면 %가 한 번 더 인코딩돼 %252B가 됩니다. 서버는 그 키를 모릅니다. 에러 메시지는 이 사정을 안 알려줍니다.

해결: Decoding 키를 쓰거나, 키에 %가 있으면 urllib.parse.unquote로 한 번 풀고 넣으세요. 참고로 같은 30번 에러가 진짜로 나는 경우도 있습니다 — 키는 계정당 하나지만 API마다 활용신청을 따로 해야 합니다.

2. JSON을 요청했는데 XML이 온다

_type=json을 붙여도 게이트웨이 단계의 에러는 XML로 옵니다.

response.json()이 여기서 터집니다. 본문 첫 글자가 <인지 먼저 보고 분기해야 합니다.

3. HTTP 200인데 실패다

기관 응답은 실패해도 HTTP 200을 줍니다. 사유는 본문 resultCode에 있습니다. raise_for_status()는 아무 말도 안 합니다. 자주 보는 코드: 03 데이터 없음 · 10/11 파라미터 오류 · 22 일일 트래픽 초과 · 30 키 미등록 · 31 기한 만료 · 32 미등록 IP.

4. 그런데 어떤 에러는 HTTP 403이다

3번과 반대로, 게이트웨이 인증 오류는 HTTP 400/403에 JSON 봉투로 오기도 합니다. 실제로 받은 응답입니다.

HTTP 403
{"OpenAPI_ServiceResponse": {"cmmMsgHeader": {
    "errMsg": "SERVICE_KEY_IS_NOT_REGISTERED_ERROR",
    "returnAuthMsg": "등록되지 않은 서비스키",
    "returnReasonCode": "30"}}}

“200이면 본문 코드 확인, 4xx면 HTTP 에러”라고 단순하게 짜면 4xx 봉투의 사유를 잃어버립니다. 상태코드와 무관하게 본문을 먼저 해석해야 합니다. 저는 단위 테스트 82개를 다 통과시킨 뒤 실서버에 처음 붙였다가 이걸로 한 번 깨졌습니다.

5. 데이터 없음이 세 가지 모양으로 온다

같은 “결과 없음”이 "items": "", "items": null, 키 자체 없음으로 옵니다. 결과가 하나면 items.item이 리스트가 아니라 dict로 오는 API도 있습니다. for it in body["items"]["item"] 한 줄이 네 가지 경우에 네 가지로 터집니다.

6. 기상청은 위경도를 안 받는다

기상청 단기예보는 **LCC 5km 격자 좌표 (nx, ny)**를 요구합니다. 서울시청(37.5665, 126.9780)은 (60, 127)입니다. 그리고 base_time 규칙이 API마다 다릅니다 — 초단기실황은 매시 정각 발표 후 40분 뒤, 초단기예보는 30분 발표 후 45분 뒤, 단기예보는 02·05·08·11·14·17·20·23시 발표 후 10분 뒤. “지금 시각”을 그냥 넣으면 아직 발표 전이라 03 NO_DATA가 납니다.

이걸 다 처리하는 라이브러리 — kpublic

여섯 번째쯤 밟고 나서 라이브러리로 만들었습니다.

  • 키 정규화: 어느 형태든 원본으로 맞추고 정확히 한 번만 인코딩
  • 본문 해석: 첫 글자로 JSON/XML 판별, 200이든 403이든 봉투를 먼저 읽음
  • items 네 가지 모양 → 전부 list[dict]
  • iter_items(): totalCount 보고 끝까지 자동 페이징
  • 재시도: 서버 일시 장애만. 22(일일 초과)와 키 오류는 재시도해봐야 트래픽만 태우므로 안 함

의존성은 httpx 하나, MIT. v0.1이라 어댑터가 기상청·에어코리아·공휴일 셋뿐입니다 — 자주 쓰는 API가 있으면 이슈로 남겨주세요.
