지금까지 만든 것들 — 전체 기록

2026년 9월 23일10 min read

  • 프로젝트
  • 기록

깊게 쓴 글은 몇 편뿐이지만, 만든 것 자체는 여기 다 적어둡니다. 끝난 것, 굴러가는 것, 접은 것 전부. 글로 풀어쓸 만한 건 링크를 답니다.

기준 하나만 지킵니다 — 실제로 돌아간 것과 실측한 숫자만. 계획했다가 안 한 건 “안 했다”고 적습니다.

굴러가는 중

🌊 어텐션 — 김 양식 황백화 조기경보

2026-06 ~ 진행 중 · 팀 프로젝트 (AI 챔피언십 출품) · 서비스

김 양식장의 황백화(백화 현상)를 위성·해양 관측 데이터로 미리 경고하는 시스템. 전국 약 1,200개 어장을 지도에 띄우고 7일 예보를 줍니다.

  • 위성(SST·클로로필)·해양 관측·기상 데이터를 하나의 시공간 큐브로 합쳐 학습
  • 백엔드 FastAPI + PostgreSQL(Timescale·PostGIS) / 프론트 React·Vite / 지도는 Leaflet
  • 문헌 기반 규칙(영양염 임계·수온 조건)과 모델 예측을 나란히 보여주는 구조 — 모델만 믿지 않게
  • 본선 통과 → 결선 진출(2026-08). 결선은 11월
  • 엣지 장비(Jetson)에서 현장 센서로 같은 지수를 계산하는 갈래도 진행 중

쓰면서 배운 게 제일 많은 프로젝트입니다. 특히 “성능이 올랐다”를 의심하는 법 — 재구현 실험에서 대조군을 같이 돌리지 않으면 개선인지 버그인지 구분이 안 된다는 걸 비싸게 배웠습니다.

📦 kpublic — 공공데이터포털 파이썬 SDK

2026-09-09 · 혼자 · PyPI · GitHub

공공데이터포털 API의 반복되는 함정(키 인코딩, 에러인데 HTTP 200, XML/JSON 혼재, 페이징)을 한 겹 감싼 SDK.

  • 어댑터 3종(기상청 단기예보·에어코리아·천문연 공휴일) 전부 실서버로 확인
  • 단위 테스트 82개 · ruff · mypy strict · wheel 격리 설치 검증
  • 실서버 호출이 문서만 봐선 못 잡을 버그 2개를 잡아줬습니다
  • 배포 자동화: 태그 하나 밀면 PyPI에 올라갑니다(토큰 없이)

📰 또리 로그 — 이 블로그

옵시디언 볼트에서 is_public: true인 노트만 골라 Quartz로 빌드해 GitHub Pages에 올립니다.

  • 발행 전 비밀 검사를 통과해야 빌드됩니다(비밀번호·키·IP·내부 경로 패턴). 하나라도 걸리면 빌드 중단
  • 매일 아침 자동 발행 + 수동 발행
  • 디자인은 두 번 갈아엎었습니다(유리패널 → 만화풍)

🛰️ AI 레이더 — 매일 아침 AI 소식 다이제스트

2026-06 ~ 운영 중 · 88편 발행

매일 08:00에 AI 에이전트가 웹을 검색해 그날의 AI 소식을 정리합니다.

  • 초안을 쓴 에이전트와 검수하는 에이전트를 분리했습니다. 검수봇이 사실 확인과 환각 필터링을 거친 뒤에만 발행
  • 출처 URL이 없는 답변은 자동 폐기합니다(환각 의심). 실제로 폐기되고 재시도로 통과한 날이 있습니다
  • 검색 API가 과부하(503)로 죽는 날이 있어서 대기·폴백을 넣었습니다

🤖 또리 삼형제 — AI 에이전트 오케스트레이션

2026-05 ~ 계속 다듬는 중

역할이 다른 AI 셋을 붙여 쓰는 작업 방식. 코드는 한 쪽이 쓰고, 리뷰는 다른 쪽이 하고, 검색은 또 다른 쪽이 합니다.

  • 사람이 직접 실행해야 하는 호출 / 자동화 가능한 호출을 등급으로 나눠 비용을 통제
  • 실패 등급(즉시 중단 ~ 고치고 계속)을 정해두고 등급대로 대응
  • 결정과 교훈은 전부 파일에 남겨 다음 세션이 이어받습니다

🎪 event-rental — 행사 장비 대여

2026-06-03 배포 · Next.js 14 + Prisma + Supabase + Vercel

장비 목록·예약·관리자 페이지. 첫 Vercel 배포라 함정을 골고루 밟았습니다 — 빌드 타임 DB 접근, Prisma Client 생성 누락, 그리고 서버리스에서 커넥션 풀이 터지는 문제(트랜잭션 모드 풀러로 해결). 이후 OAuth 키 발급 단계에서 멈춰 있습니다.

2026-06-07~08

🎬 video-task — 홍보영상 자동 생성

2026-06-20~21 · 보류

📈 chaos — 자동매매 실험

2026-06-06 · 보류

전략 백테스트까지만. 실거래 코드는 만들지 않았습니다 — 손절 로직 없는 전략은 코드로 옮기지 않는다는 규칙을 먼저 세웠고, 기획이 거기까지 안 갔습니다.

🖥️ WSL2 → Windows 네이티브 전면 이전

2026-08-23

개발 환경 전체(CLI 3종·node 프로젝트 4개·데몬·예약 작업 6종)를 WSL2에서 네이티브로 옮기고 배포판을 삭제했습니다. 옮기는 도중에 발견한 버그가 여럿이고, 삭제 직전에 WSL에만 있던 SSH 개인키 2개를 발견했습니다. 지우기 전에 뭐가 들어있는지 보는 습관의 중요성.
