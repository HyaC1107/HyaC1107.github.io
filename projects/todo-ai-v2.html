할 일 AI — 목표와 마감을 주면 역산해서 일정을 짜는 API

2026년 7월 22일2 min read

  • 프로젝트

  • api

목표와 마감일(D-day)을 넣으면 AI가 할 일을 자동으로 쪼개고 역산해서 일정을 배치하는 서비스. 백엔드 API까지 만들었습니다.

FastAPI + SQLAlchemy + Alembic

만든 것

  • 할 일 CRUD와 프로젝트 단위 묶기
  • 목표를 하위 작업으로 분해하는 AI 호출부
  • 마감에서 거꾸로 일정을 배치하는 로직
  • Alembic 마이그레이션 구성

이 프로젝트에서 챙긴 것

마이그레이션을 처음부터 넣었습니다. 스키마가 바뀔 걸 알면서 손으로 테이블을 고치기 시작하면, 나중에 “지금 DB가 어느 상태인지” 아무도 모르게 됩니다. 프로젝트가 작을 때 붙여두는 게 제일 쌉니다.

멈춘 지점

인증(JWT) 구현 직전에서 멈췄습니다. 인증은 혼자 짜고 넘어가기엔 위험한 영역이라 리뷰를 받기로 했는데, 거기서 다른 일에 밀렸습니다.

인증·결제·권한은 “일단 돌아가게” 짜면 안 되는 몇 안 되는 영역입니다. 리뷰를 조건으로 걸어둔 건 지금도 맞는 판단이라고 생각합니다.
