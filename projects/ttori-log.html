또리 로그 — 이 블로그는 옵시디언 볼트에서 자랍니다

지금 보고 계신 이 사이트입니다. 따로 글을 쓰는 게 아니라, 평소 쓰는 옵시디언 볼트에서 공개 표시된 노트만 빠져나와 웹이 됩니다.

구조

옵시디언 볼트
  └ blog/ 안에서 is_public: true 인 노트
  └ daily/ai-radar/ 전부
        ↓  blog-sync.py  ← 비밀 검사
     Quartz 5 빌드
        ↓
   GitHub Pages

매일 아침 자동으로 한 번 돌고, 새 글을 올릴 땐 수동으로도 돕니다.

제일 중요한 부품은 디자인이 아니라 비밀 검사입니다

개인 볼트가 소스라는 건 서버 비밀번호·API 키·내부 경로가 같은 저장소에 있다는 뜻입니다. 실수 한 번이면 그게 그대로 웹에 박힙니다.

그래서 발행 스크립트는 복사 전에 패턴을 훑고, 하나라도 걸리면 빌드 자체를 중단합니다(exit 1).

  • 서버 접속 암호와 그걸 적는 흔한 표기 형태
  • API 키 계열(PyPI·OpenAI·Google·AWS·GitHub 토큰, 공공데이터 서비스키)
  • IP 주소, 내부 절대경로, 개인키 파일 확장자
  • 제휴 계정 태그

실제로 이 검사가 자기 글도 막았습니다. 바로 이 글입니다. 위 목록을 처음엔 실제 패턴 예시로 적었는데 검사기가 2건을 잡아내며 빌드를 세웠습니다. 표현을 풀어 쓰고 나서야 통과했습니다.

불편하지만 그게 맞습니다 — 막아야 할 걸 막는 검사는 가끔 나까지 막아야 정상입니다. 예외를 두기 시작하면 그 예외로 새어 나갑니다.

쌓인 것

  • 글 15편 + AI 레이더 88편
  • 댓글은 GitHub Discussions를 DB 삼아 붙였습니다(서버 없음)
  • 글마다 하단에 **“초안은 AI가 썼고, 사람이 검토했는지”**를 표시합니다. 검토 전이면 “대기 중”이라고 그대로 나갑니다

배운 것

디자인을 두 번 갈아엎었고, Quartz 함정도 여럿 밟았습니다 — 그건 따로 적었습니다.
